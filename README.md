# Физика Sprint — подготовка к зачёту

Мобильное веб-приложение на русском языке для подготовки к зачёту «Физика 2: электричество и магнетизм». Работает как обычный сайт, сохраняет прогресс в браузере и поддерживает установку на экран iPhone через Safari.

## Что внутри

- Все **64 темы** из файла «Вопросы к зачёту».
- Подробный разбор каждой темы: ключевая формула, физический смысл, короткий вариант ответа на зачёте и частая ошибка.
- Отдельная тренировка **билета № 1** по всем 15 пунктам из загруженного билета.
- Смешанные тесты и повторение сложных вопросов с немедленным объяснением ответа.
- Карточки для активного вспоминания.
- Шпаргалка с поиском, фильтром по разделам, избранным и копированием формул.
- Прогресс по темам, правильные ответы и серия учебных дней.
- PWA / service worker: после первого открытия сайт может работать офлайн.
- Адаптация к экрану iPhone, верхняя навигация вместо нижней панели, тёмная тема, safe areas и reduced motion.

## Как опубликовать через GitHub Pages

1. Создай новый репозиторий на GitHub, например `fizika-sprint`.
2. Загрузи **содержимое этой папки** в корень репозитория. В корне должны лежать `index.html`, `styles.css`, `app.js`, `manifest.json`, `icon.svg` и `sw.js`.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажми **Save**.
5. Открой появившийся адрес GitHub Pages в Safari на iPhone. Для добавления на домашний экран нажми **Поделиться → На экран «Домой»**.

Если GitHub предложит адрес вида `https://USERNAME.github.io/REPOSITORY/`, всё нормально: пути в проекте относительные, поэтому сайт работает и в подпапке репозитория.

## Локальный запуск для проверки

Можно открыть `index.html` в браузере для быстрой проверки интерфейса. Для проверки офлайн-режима/service worker необходим HTTP(S), например GitHub Pages.

## Данные и приватность

Прогресс сохраняется в `localStorage` браузера. Приложение не подключается к серверу и не отправляет ответы или статистику. При очистке данных сайта браузером сохранённый прогресс может удалиться. Контент приложения находится в `app.js`, его можно редактировать без сборщика и установки зависимостей.

## Основа материалов

Содержимое подготовлено по материалам пользователя:
- «вопросы к зачёту.pdf» — список из 64 тем;
- «Зачет_Билет№1.pdf» — 15 вопросов билета № 1;
- «2 Лекции ч 2 В.В., Стерлядкин испр2.pdf» — определения и формулы курса.

В отдельных карточках добавлены поясняющие формулировки и оговорки по условиям применимости. Особенно внимательно сверяй с лекциями геометрические обозначения углов в формуле поля конечного провода и модели диэлектриков/проводников.
